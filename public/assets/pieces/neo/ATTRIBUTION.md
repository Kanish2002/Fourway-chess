# Neo pieces

The six white Neo PNG files are Chess.com's piece artwork, bundled so the requested silhouettes work without an external image request. Fourway applies display-time color filters for Red, Blue, Yellow and Green; original PNG geometry is unchanged.

Source mirror: https://github.com/GiorgioMegrelli/chess.com-boards-and-pieces/tree/v2.x/pieces/ejgfv

The mirror's `default-config.json` identifies `ejgfv` as Neo, downloaded from `https://assets-themes.chess.com/image/ejgfv/150/{piece}.png`.

Chess.com retains ownership of its artwork. This repository does not claim the artwork as original or apply a software license to it. Fourway is independent and is not affiliated with Chess.com.
